# 🐾 Pet Adoption Website

A modern and responsive **Pet Adoption Website** built using **HTML5** and **CSS3**. The website helps users explore adorable pets available for adoption through a clean and user-friendly interface.

## ✨ Features

- 🏠 Modern Home Page
- 🐶 Featured Pets Section
- ❤️ Adopt Me Buttons
- 🏡 Why Adopt From Us Section
- 📱 Fully Responsive Design
- 🎨 Clean and Attractive UI
- ⚡ Smooth Hover Effects
- 📞 Footer with Social Media Icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome
